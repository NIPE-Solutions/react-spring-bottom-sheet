# Version 5.0.0 Stable Sign-off

Release candidate: `5.0.0` (unpublished)

Evidence prepared: 2026-09-03

## Carried-forward runtime evidence

The following checks were completed for `5.0.0-alpha.0` and are carried
forward from [the alpha sign-off](v5-alpha.0-signoff.md). Changes after the
alpha affect release policy and automation, planning documentation, website
release-state presentation, and tests; they do not alter the package runtime
behavior assessed by these checks.

- [x] VoiceOver on macOS or iOS.
- [x] Keyboard-only modal and non-modal operation in production Chrome. Modal
      open and Escape dismissal restored focus to the trigger; the non-modal
      sheet left surrounding page controls operable.
- [x] iOS Safari on a physical device.
- [x] Android Chrome on a physical device.

## Remaining stable release gates

- [x] Complete stable automation, including clean installation, release
      readiness, browser suites, website browser suites, and the production
      dependency audit.
  - On macOS 14.6.1 ARM64, `npm ci`, `npm run release:check`, and
    `npm audit --json` passed. The audit contained zero production and zero
    development advisories.
  - Native browser runs passed 42 library tests across Chromium, Firefox, and
    Chromium touch and 108 website tests across Chromium and Firefox.
  - Playwright 1.62.1's frozen macOS 14 WebKit override is incompatible with
    its client protocol, so a clean archive of commit `47d9d63` was also
    verified with WebKit revision 2336 in the matching official
    `mcr.microsoft.com/playwright:v1.62.1-noble` image. All 14 library and 54
    website WebKit tests passed under the strict CI reporter.
- [ ] GitHub browser checks for the exact stable candidate across every required
      browser and touch project.
- [x] Exact packed `5.0.0` consumers for ESM, CommonJS, TypeScript, styles,
      package metadata, audit, and size contracts.
- [ ] Production deployment of the promoted stable candidate, including the
      canonical domain, sitemap, social metadata, representative documentation,
      and examples.
- [ ] External publishing protection, including the npm trusted publisher and
      GitHub `npm` environment restrictions for the stable workflow.

## Publication decision

Publication remains blocked until every remaining stable release gate is
complete and backed by precise evidence.
