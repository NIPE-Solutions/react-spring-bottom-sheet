# Version 5.0.0 Stable Sign-off

Release candidate: `5.0.0` (unpublished)

Evidence prepared: 2026-09-03

## Carried-forward runtime evidence

The following checks were completed for `5.0.0-alpha.0` and are carried
forward from [the alpha sign-off](v5-alpha.0-signoff.md). Changes after the
alpha affect release policy and automation, planning documentation, website
release-state presentation, and tests; they do not alter the package runtime
behavior assessed by these checks.

- [x] VoiceOver on macOS or iOS.
- [x] Keyboard-only modal and non-modal operation in production Chrome. Modal
      open and Escape dismissal restored focus to the trigger; the non-modal
      sheet left surrounding page controls operable.
- [x] iOS Safari on a physical device.
- [x] Android Chrome on a physical device.

## Remaining stable release gates

- [x] Complete stable automation, including clean installation, release
      readiness, browser suites, website browser suites, and the production
      dependency audit.
  - On macOS 14.6.1 ARM64, `npm ci`, `npm run release:check`, and
    `npm audit --json` passed. The audit contained zero production and zero
    development advisories.
  - Native browser runs passed 42 library tests across Chromium, Firefox, and
    Chromium touch and 110 website tests across Chromium and Firefox.
  - Playwright 1.62.1's frozen macOS 14 WebKit override is incompatible with
    its client protocol, so a clean archive of commit `47d9d63` was also
    verified with WebKit revision 2336 in the matching official
    `mcr.microsoft.com/playwright:v1.62.1-noble` image. A clean archive of the
    final reviewed code commit `2b9170f` passed all 14 library and 55 website
    WebKit tests under the strict CI reporter.
- [x] GitHub Actions run `33765109142` passed the Node 24 quality gate and all
      browser jobs for stable candidate `2b9170f`: Chromium, Firefox, WebKit,
      and Chromium touch.
- [x] Exact packed `5.0.0` consumers for ESM, CommonJS, TypeScript, styles,
      package metadata, audit, and size contracts.
- [x] Production deployment of promoted `main` commit `380b162`.
  - Vercel production branch tracking was moved from `v5` to `main`, custom
    production-domain assignment remained enabled, and the exact promoted
    deployment was rebuilt successfully in the Production environment.
  - `https://react-spring-bottom-sheet.nipesolutions.com/` served the prepared
    `5.0.0` presentation with its canonical and Open Graph URLs, working live
    sheet interaction, installation documentation, custom-portal example,
    sitemap, robots file, and social image.
- [x] External publishing protection for the stable workflow.
  - npm trusted publishing is bound to GitHub Actions repository
    `NIPE-Solutions/react-spring-bottom-sheet`, workflow `release.yml`, and
    environment `npm`.
  - The GitHub `npm` environment requires approval by `Cylop`, prevents
    administrator bypass, and permits deployment only from `main` and `v5`.

## Publication decision

Every stable release gate is complete. Publication may proceed only from the
exact merged sign-off commit through the protected `Release` workflow and with
the maintainer's explicit authorization.
