The following checks were completed for `5.0.0-alpha.0` and are carried
forward from [the alpha sign-off](v5-alpha.0-signoff.md). Changes after the
alpha affect release policy and automation, planning documentation, website
release-state presentation, and tests; they do not alter the package runtime
behavior assessed by these checks.

      open and Escape dismissal restored focus to the trigger; the non-modal
      sheet left surrounding page controls operable.
- [x] iOS Safari on a physical device.
- [x] Android Chrome on a physical device.
